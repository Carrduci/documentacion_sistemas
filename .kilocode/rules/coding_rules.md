# Reglas de Codificación para documentacion_sistemas

**Nota: Estas reglas pueden mejorarse con el tiempo según patrones observados, sugerencias del usuario o evoluciones tecnológicas.**

## Estructura de Documentos
- **Carpetas por categorías** en docs/.
- **Archivos kebab-case** sin espacios.
- **Índice automático** con _sidebar.md.

## Sintaxis Markdown
- **Encabezados jerárquicos** consistentes.
- **Código resaltado** con lenguajes.
- **Tablas** para datos estructurados.

## Docsify
- **Plugins** para funcionalidades avanzadas.
- **Tema consistente** con CARRDUCI branding.
- **Búsqueda integrada**.

## Contenido
- **Idioma español** obligatorio.
- **Ejemplos prácticos** en código.
- **Enlaces internos** funcionales.

## Actualización
- **Script automático** para sidebar.
- **Commits convencionales**.
- **Versionado** de documentación.

## Calidad
- **Revisión de pares** para cambios importantes.
- **Consistencia** en terminología.
- **Actualidad** con código.

Estas reglas mantienen documentación clara y útil.
